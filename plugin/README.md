# ZHUANG-AI插件 · Photoshop 面板

![ZHUANG-AI插件 logo](assets/logo.svg)

一个参考桌面微信界面的 Photoshop UXP 插件：选预设、写提示词、运行、查看图片，并把结果精确回贴到 Photoshop。

主链路是 **预设 → 提示词 → 运行 → 查看 / 回贴 / 保存**；另外把预拆分里的 **文字对话、辉光、图片特效、AI 超分、ComfyUI** 收进了「对话 / 工具」。

> 项目主页：<https://github.com/shengmojiaogexing/ZHUANG-AI> · 许可证：GPL-3.0

## 功能

- 创作页：选区自动作为参考图；没有选区时用整幅画布兜底；没有文档时可直接生成并新开文档。
- 生图数量：输入框左下角的「图层」图标里选 1–8 张（图标角标显示当前数量），**多张会并行同时请求**（不会一张接一张排队）；第一张按“生成后自动回贴”处理，其余结果以卡片展示，点「回贴 PS」再决定贴哪张，避免多张叠在一起。支持一次出多张的渠道（Google / xAI / 火山 / OpenAI / NewAPI 等）仍用单个请求的 n 参数，平台内部并行。
- 后台生成：生成期间可以切到别的文件继续修图；回贴时临时切回原文件，贴完和抓完预览后自动切回你正在编辑的文件。
- 回贴对齐：选区先走 DOM，读不到再走 batchPlay；置入、缩放、栅格化后都会再对齐一次目标矩形，避免大图 / 16 位文档回贴偏移。
- 回贴结果：回贴图层会自动放进一个同名图层组，并给组加一个白色蒙版（可直接涂抹）；建组 / 加蒙版失败会自动回退成普通图层，不影响回贴。
- 运行日志：左侧主菜单「日志」（设置上方），记录生成、选区、回贴、ComfyUI、对话和异常；支持按级别筛选、复制和清空，只留最近 240 条在本机。
- 参考图：输入框左下角三个小图标——笑脸打开预设表情包；文件夹从文件选择参考图；图片图标是「智能抓取」：有选区抓选区，没有选区就抓整幅画布。最多 3 张；抓取时直接在 Photoshop 里按最长边 1400px 读取，大画布 / 4K 图不会再先读全尺寸再缩放，点一下就能抓完。
- 生图参考图：最多 3 张，UXP 文件选择器读取 PNG / JPG / WebP / GIF；参考图和选区会一起传给生图接口。
- 预设：和幻梦圆环共用同一份；首次导入圆环自带的 68 条预设和它的 23 个分类，之后在插件里新建 / 编辑 / 删除，改完实时推给圆环。
- 选预设：**不用启动幻梦圆环也能直接选**——输入框左下角「笑脸」打开微信表情包式预设面板（分类 Tab + 网格），点一下就把提示词填好并收起；预设页里**左键套用、右键编辑**（每张卡片右上角有「编辑」小按钮，悬停显示；UXP 右键不触发时用它），页顶有搜索框，可按预设名称 / 分类 / 提示词筛选；圆环连上后仍可在圆环里选。
- 界面：按桌面微信重做——字号整体加大、护眼亮灰背景、聊天气泡 / 输入条 / 预设面板更接近微信（消息间距按微信节奏：不同人 18px、连续同人 8px，头像 36px）；**5 个简化 SVG 图标与「运行」同一行，所有弹出面板（预设/数量）浮在输入框上方**，模型点开设置、数量点开 1–8 面板；**预设抽屉和数量面板右上角有 X 关闭按钮，点面板外或按 Esc 也会收起**；中文界面统一 400 / 600 两档字重，不再「有的细有的粗」；**设置页按 Tab 分组（外观 / 模型 / 连接 / ComfyUI / 生成），一屏一组不再长滚动**；设置 → 外观有字号滑块（90%–150%）和三种配色（亮灰护眼 / 白色 / 黑色）；工具页数值参数改成自定义滑块；生成等待时有「正在输入」点动效。
- 滚动条：所有页面 / 聊天 / 列表 / 弹窗都换成自绘滚动条（UXP 原生滚动条无法定制，所以改为内部 transform 滚动）；支持**滚轮、拖拽滑块、点击轨道、键盘 ↑↓ / PgUp / PgDn / Home / End**；嵌套列表优先滚内层、到边界才滚外层；输入框内部的文本编辑滚动仍交给系统（不影响输入光标）；**按需测量、只更新内容变化的滚动容器**（消息再多也不会每次全量重排），页面从隐藏切回可见时会补测量，右侧滑块不会漏初始化。
- 输入框：点运行发出后自动清空，提示词留在聊天气泡里；进度文案只保留必要信息。
- 圆环连接状态：预设页和创作页都有状态点；圆环未启动时插件会持续重连。
- 运行：支持 GRS、Google AI Studio、xAI、火山方舟 SeeDream、Vertex AI、OpenAI 兼容和 New API 中转；各渠道的 Key / URL 独立保存，模型名可在模型面板底部自定义。
- GRS 模型：按 grsai.com 模型列表同步了 17 个图片模型（Nano Banana 2.1 / 2 / Pro / Lite / Fast / CL / VIP，GPT Image 2 / 2.5 / 2.6），默认 Nano Banana 2.1；分辨率会按模型能力自动夹取（如 CL 版最多 1K；3K 档在 GRS 会落到 4K 或 2K）。纯文本 / 视频模型不进生图模型列表。
- 查看图片：生成结果以聊天气泡展示，点开预览；刚回贴的结果会从 Photoshop 画面生成缩略图，保存和回贴使用完整原图。
- 回贴：复用 `04-图片放回/place-image.js` 的精确置入逻辑（placeEvent → 读边界 → 缩放 → 移动 → 栅格化），完成后自动建同名图层组并加白色蒙版。
- 历史：自动记录最近 30 次，一页显示全部记录，不再每 6 张分页；缩略图存在本地索引，原图存在插件数据目录；可重新回贴、保存、删除、清空。
- 存储目录：用 UXP 文件夹选择器设置，保存原图时写入；目录令牌会持久化。
- 设置：模型选择、分辨率 1K/2K/3K/4K、生成后自动回贴、**回贴时融合校色**开关、每个渠道独立的 API Key / 接口地址、自定义模型名，以及「外观」里的字号滑块和三种配色；右上角和连接区都有“保存”，输入后失焦也会自动保存。
- 对话：多轮文字 / 带选区视觉问答，记忆 8 轮；对话模型跟随当前图片渠道（GRS / Google / Vertex / 火山 / OpenAI）。
- 辉光：柔光 / 白光 / 星芒 / 横向拉丝，本地 CPU 计算，写入屏幕混合新图层。
- 图片特效：本地热浪 / 气流 / 刀光，以及 AI 能量拖尾 / 霓虹描边 / 魔法阵。
- AI 超分：2× / 3× / 4× 切片放大，逐块回贴；使用当前生图模型。
- 工具页顶部都有当前画面预览，处理完自动刷新为结果预览，点图可放大。
- ComfyUI：左侧导航独立入口（与创作平级）。连接本机 / 局域网 ComfyUI 后自动读取它的 `workflows` 目录里的工作流列表，点一份就直接载入并转换，不需要手动粘贴或导入 JSON；服务地址在「设置 → ComfyUI」里配置。
- ComfyUI 内置工作流：本机 ComfyUI 的两份工作流已内置，「内置 · 图生图带放大（默认）」排在最前；主图节点标成 `#06 主图`，点旁边的「读取选区」就能把 Photoshop 选区上传成主图再运行。另有「内置 · 文生图带放大」，带 `#01 正向提示词 / #02 LoRA / #03 画幅` 参数。工作流 JSON 里自带的固定提示词已清空，提示词只由插件面板填写。
- ComfyUI 参数：只显示工作流里 `#` 标记的参数，其余全部隐藏；主图 / 图片输入参数旁边有「读取选区」，会把 Photoshop 当前选区上传到 ComfyUI 并自动填成主图文件名；下拉框是自定义选择器，数字 / 文本 / 开关 / 随机种子统一插件风格，运行前把改动写回工作流。
- 图标：全部为内联单色 SVG，没有 PNG 图标、字体图标或 emoji。

## ComfyUI（本地）

- 只支持本地 / 局域网 ComfyUI：服务地址在「设置 → ComfyUI → ComfyUI 地址」里填，默认 `http://127.0.0.1:8188`。
- 内置工作流：`js/workflows-builtin.js` 从本机 ComfyUI `user/default/workflows` 导出（主图节点加了 `#06` 标记、清理了悬空连线、清空了固定提示词）；载入时会把界面格式转成 API 格式，所以仍需要连上 ComfyUI 才能拿到节点定义。文生图内置工作流的 LoRA 源文件本身没选值，运行前先在 `#02 LoRA` 里选一个。
- 运行前会检查 `#` 参数：主图还没选（`#06 主图` 为空）或必填下拉没选时直接提示，不会把空参数发给 ComfyUI（空主图会让服务端报权限错误）。「读取选区」上传走原始字节（ArrayBuffer）而不是 Blob，避免 UXP 把 Blob 的 MIME 拼进 Content-Type 导致 `/upload/image` 返回 500。
- 本地地址会记住：`localStorage['zhuang_ai_comfy_local_url_v1']`。
- 开源版不包含任何云端 ComfyUI 渠道与离线授权码校验，仓库里没有云端地址、授权码或密钥。

## 安装

### 方式一：UXP Developer Tool（推荐）

1. 安装 Adobe **UXP Developer Tool**（在 Creative Cloud 里搜索）。
2. 打开 UXP Developer Tool，点 **Add Plugin**。
3. 选择本目录里的 `manifest.json`。
4. 点插件条目右侧的 **Load**。
5. 回到 Photoshop，在 **增效工具 / 插件** 菜单里打开 **ZHUANG-AI插件**。

### 方式二：外部插件目录

把本目录（`plugin/`）整个复制到：

```
C:\Program Files\Common Files\Adobe\UXP\Plugins\External\com.zhuang.ai.panel
```

重启 Photoshop，在 **增效工具 / 插件** 里打开。不同版本目录可能不同；找不到时优先用方式一。

> 本插件需要 Photoshop 26.0 或更高版本。

## 第一次使用

1. 幻梦圆环可选：想用圆环选预设就从本仓库 `ring/` 启动对应平台的圆环（`127.0.0.1:8799`，插件自动连）；不启动也能在插件里直接选预设。
2. 打开一张图，用选区框出要改的范围；不框就是整幅画布。参考图点输入框左下角图标：文件夹选文件，图片图标智能抓取（有选区抓选区，没选区抓整幅画布）。
3. 在 **设置 → 高级设置 → API 模型选择** 里选模型。
4. 填对应渠道的 API Key 和接口地址（Google 现在也可以填代理地址）；模型列表里没有的模型，在面板底部「自定义模型名」里填入后点使用。若你之前装过幻梦 AI，Key 和模型会自动沿用。
5. 需要保存原图时，在 **存储目录** 里选一个文件夹。
6. 点输入框左下角「笑脸」打开预设表情包，点一个预设，提示词会自动填好；也可以自己写提示词，点 **运行**。圆环连上后也能在圆环里选。
7. **对话** 用于问修图问题；**工具** 里有辉光、特效、超分（数值参数用滑块调整）；ComfyUI 是左侧独立入口。字号和配色在 **设置 → 外观** 里调。
8. 需要回贴后直接校色时，在 **设置 → 生成** 打开“回贴时融合校色”。回贴结果会自动变成图层组并加一个白色蒙版。
9. 用 ComfyUI 时：先在「设置 → ComfyUI」里确认 ComfyUI 地址（默认 `http://127.0.0.1:8188`），回到 ComfyUI 页会自动读取本地工作流。默认载入内置的「图生图带放大」工作流，点 `#06 主图` 旁的「读取选区」把 PS 选区传上去，再运行。

## 幻梦圆环（可选）

圆环源码在本仓库 `ring/`（Windows C# / PowerShell、macOS Swift 三套）。圆环是 WebSocket 服务端（`ws://127.0.0.1:8799`），插件是客户端：

- 插件连接后把自己的预设按 `{category, items:[{name,prompt}]}` 推给圆环；
- 圆环在线时优先用插件这份，所以两边分类/预设实时一致；
- 圆环点预设后发 `applyPreset`，插件按「分类 + 名字」精确定位，避免同名预设串条；
- 插件里新增/编辑/删除预设后立即重新推 state；
- 圆环没启动时插件显示未连接，并在后台自动重连。

预设分类全部来自圆环的 `presets.json`（23 个分类、68 条），不再使用旧的内置 6 条。插件里可以改任意一条，包括圆环自带的。**预设选择不依赖圆环**：插件创作页顶部和预设页都能直接选；圆环在线时两边同步。

## 数据位置

- API Key、模型、分辨率：`localStorage['huanmeng_config']`（与幻梦 AI 同一份）。
- UI 偏好（含字号 / 配色）、存储目录令牌、草稿：`localStorage['zhuang_ai_ui_v1']`。
- 预设（圆环 + 自定义）：`localStorage['zhuang_ai_presets_v1']`；首次导入标记是 `zhuang_ai_ring_presets_seeded_v1`。
- 历史索引和缩略图：`localStorage['zhuang_ai_history_v1']`。
- 历史原图：UXP 插件数据目录下的 `history/` 文件夹；最多保留 30 张。
- 保存原图：设置里选择的目录。
- ComfyUI 地址：`localStorage['zhuang_ai_comfy_local_url_v1']`。

API Key 只保存在本机浏览器存储里，不会上传到除你选择的模型接口以外的位置。

## 关于「预拆分」

当前版本接入了生成主链路和工具：

- `00-核心`：设置、模型解析、PS 宿主、像素与置入。
- `01-生图API`：多渠道路由、生图、响应取图。
- `02-文字对话`：多轮文字 / 选区视觉问答。
- `04-图片放回`：精确回贴。
- `05-放回校色`：算法 + 当前图层融合校色。
- `06-辉光工具`：多尺度辉光，本地计算。
- `07-图片特效`：SpaceFX 与 AI VFX。
- `08-超分辨率`：AI 切片超分。
- `03-ComfyUI`：接入了 client + convert；面板直接读 ComfyUI 的
  `/userdata?dir=workflows&full_info=true` 工作流列表，点选后读
  `/userdata/{file}`，界面格式再用 `/object_info` 转成 API 格式。

没有搬原 `comfy-panel.js` 那套 DOM，但接入了 `comfy-form.js` 的参数模型：
下拉 / 数字 / 文本 / 开关 / 种子随机都在插件里改，运行时
`applyParamValues()` 写回 API 工作流。
